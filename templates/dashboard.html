About QuakeScope — Global Earthquake Intelligence

QuakeScope is an open-source geospatial intelligence and monitoring dashboard designed to provide real-time visibility into worldwide seismic activity. It transforms raw GeoJSON telemetry from the United States Geological Survey (USGS) and software analytics from GitHub into interactive, accessible, and actionable intelligence.

Data Ingestion & Reliability

  • USGS Earthquake Hazards Program: Standard GeoJSON feeds updated every minute. Supports M4.5+, M2.5+, and all recorded events globally.
  • GitHub Search API: Popular Python repository trends tracked with star counts and metadata.
  • Zero-Data-Loss Architecture: Atomic file writing and local caching ensure that temporary network glitches or API rate limits never wipe out previous intelligence.
  • Direct Client-Side Refresh: Visitors can query the live USGS CORS endpoint directly from the browser to refresh data without waiting for static deployment cycles.

Technology Stack & Standards

Built with Python 3, Pandas, Leaflet.js, Plotly, and semantic HTML5/CSS3. Fully responsive across desktop, tablet, and mobile devices (tested down to 360px). Adheres to WCAG 2.1 accessibility guidelines with high-contrast palette and keyboard navigation.
